# 智能手机电池连续时间耗电建模报告

## 摘要

本报告建立了一个基于锂离子电池特性的智能手机电池连续时间数学模型，以时间为函数精确描述电池的充电状态（SOC）变化。模型综合考虑了屏幕使用、处理器负载、网络活动、GPS使用、后台应用以及温度等多种影响因素，通过微分方程组描述SOC动力学，并结合扩展卡尔曼滤波器实现实时SOC估计。模型可预测不同使用场景下的剩余放电时间，并通过蒙特卡洛方法量化预测不确定性。

---

## 1. 引言

### 1.1 研究背景

智能手机电池续航是用户体验的核心指标之一。然而，电池耗电行为的复杂性使得准确预测剩余使用时间成为一个挑战。影响因素包括：

- **使用模式**：屏幕亮度、处理器负载、网络活动
- **环境条件**：温度对电池容量的影响
- **电池老化**：循环次数对有效容量的影响
- **后台活动**：应用程序的隐性耗电

### 1.2 研究目标

建立一个连续时间数学模型，满足以下要求：

1. 使用连续时间微分方程描述SOC动态变化
2. 考虑多种使用场景和环境因素
3. 预测剩余放电时间并量化不确定性
4. 结合卡尔曼滤波实现在线SOC估计

## 2. 数学模型建立

### 2.1 模型框架

我们采用基于能量守恒和库仑计数的方法建立模型。核心思想是：

**电池SOC的变化率等于放电电流除以电池有效容量**

```
dSOC/dt = -I(t) / Q_eff - k_self * SOC
```

其中：
- `SOC`：充电状态 (State of Charge)，范围 [0, 1]
- `I(t)`：放电电流 (A)
- `Q_eff`：有效容量 (Ah)
- `k_self`：自放电系数

### 2.2 核心微分方程组

#### 2.2.1 主方程：SOC动力学

```
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│    dSOC        P_total(t)                                          │
│   ────── = - ───────────────── - k_self · SOC                      │
│     dt       V(SOC) · Q_eff                                        │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

**方程说明**：
- `P_total(t)`：总功耗（W），由各组件功耗叠加得到
- `V(SOC)`：开路电压，是SOC的非线性函数
- `Q_eff`：有效容量，受温度和老化影响
- `k_self`：自放电系数（约 0.0001/h）

#### 2.2.2 开路电压-SOC关系（改进的Shepherd模型）

```
V(SOC) = V₀ - K · (1-SOC)/SOC + A · exp(-B · (1-SOC))
```

**参数说明**：
| 参数 | 含义 | 典型值 | 来源 |
|------|------|--------|------|
| V₀ | 电池常数电压 | 4.2 V | 锂离子电池规格 |
| K | 极化常数 | 0.1 V | 实验拟合 |
| A | 指数区振幅 | 0.2 V | Tremblay模型[2] |
| B | 指数区常数 | 3.0 | Tremblay模型[2] |

#### 2.2.3 有效容量模型

有效容量受温度和老化两个因素影响：

```
Q_eff = Q_nom · f_T(T) · f_age(n)
```

**温度修正因子**（基于Arrhenius方程）：

```
                    ⎛  Ea     1     1   ⎞
f_T(T) = exp ⎜- ─── · ⎛─── - ───⎞ ⎟
                    ⎝   R    ⎝ T   T_ref⎠⎠
```

其中：
- `Ea = 20000 J/mol`：活化能
- `R = 8.314 J/(mol·K)`：气体常数
- `T_ref = 298.15 K`：参考温度（25°C）

**老化修正因子**：

```
f_age(n) = 1 - α · n
```

其中：
- `α = 0.0002`：每循环容量衰减率
- `n`：充放电循环次数

### 2.3 功耗模型

总功耗由各组件功耗叠加：

```
P_total = P_screen + P_cpu + P_gpu + P_network + P_gps + P_other
```

#### 2.3.1 屏幕功耗模型

```
P_screen = (P_base + α_b · brightness + α_s · (size-5) + α_r · (refresh-60)) · I_on
```

| 参数 | 含义 | 典型值 |
|------|------|--------|
| P_base | 基础功耗 | 100 mW |
| α_b | 亮度系数 | 400 mW/unit |
| α_s | 尺寸系数 | 50 mW/inch |
| α_r | 刷新率系数 | 2 mW/Hz |

#### 2.3.2 处理器功耗模型

考虑DVFS（动态电压频率调节）的非线性效应：

```
P_cpu = P_idle + (P_active - P_idle) · load^β
```

其中 `β = 1.5` 表示功耗-负载的非线性关系。

#### 2.3.3 网络功耗模型

```
P_network = P_wifi + P_cellular
```

蜂窝网络功耗受信号强度影响：

```
P_cellular = P_base · (1 + k_signal · (1 - signal_strength))
```

弱信号需要更高的发射功率，显著增加耗电。

### 2.4 扩展状态空间模型（用于卡尔曼滤波）

为提高SOC估计精度，采用二阶RC等效电路模型：

```
状态向量: x = [SOC, V_RC1, V_RC2]ᵀ

状态方程:
┌ dSOC/dt   ┐   ┌ -I/Q_eff                        ┐
│ dV_RC1/dt │ = │ I/C₁ - V_RC1/(R₁·C₁)           │
└ dV_RC2/dt ┘   └ I/C₂ - V_RC2/(R₂·C₂)           ┘

观测方程:
V_terminal = V_OCV(SOC) - V_RC1 - V_RC2 - I·R₀
```

## 3. 卡尔曼滤波器设计

### 3.1 扩展卡尔曼滤波器（EKF）

由于SOC与电压之间存在非线性关系，采用EKF进行状态估计。

#### 3.1.1 离散化状态方程

```
x_{k+1} = x_k + Δt · f(x_k, u_k) + w_k
y_k = h(x_k) + v_k
```

其中：
- `w_k ~ N(0, Q)`：过程噪声
- `v_k ~ N(0, R)`：测量噪声

#### 3.1.2 EKF更新步骤

**预测步骤**：
```
x̂_{k|k-1} = x̂_{k-1|k-1} + Δt · f(x̂_{k-1|k-1}, u_{k-1})
P_{k|k-1} = F_k · P_{k-1|k-1} · F_kᵀ + Q
```

**更新步骤**：
```
K_k = P_{k|k-1} · H_kᵀ · (H_k · P_{k|k-1} · H_kᵀ + R)⁻¹
x̂_{k|k} = x̂_{k|k-1} + K_k · (y_k - h(x̂_{k|k-1}))
P_{k|k} = (I - K_k · H_k) · P_{k|k-1}
```

#### 3.1.3 雅可比矩阵

状态转移雅可比矩阵：
```
        ⎡ 1    0           0        ⎤
F_k =   ⎢ 0    1-Δt/τ₁    0        ⎥
        ⎣ 0    0           1-Δt/τ₂  ⎦
```

观测雅可比矩阵：
```
H_k = [dV_OCV/dSOC, -1, -1]
```

### 3.2 自适应卡尔曼滤波

采用Sage-Husa算法自适应调整噪声协方差：

```
R̂_k = (1-b)·R̂_{k-1} + b·(y_k - ŷ_k)²
```

其中 `b = 0.98` 为遗忘因子。

## 4. 多目标优化

### 4.1 优化目标

参数估计问题被形式化为多目标优化：

**目标1**：最小化SOC预测误差
```
J₁ = √(1/N · Σ(SOC_model - SOC_measured)²)
```

**目标2**：最小化电压预测误差
```
J₂ = √(1/N · Σ(V_model - V_measured)²)
```

### 4.2 NSGA-II算法

采用非支配排序遗传算法II（NSGA-II）求解Pareto最优解集：

1. **非支配排序**：将种群分层为多个Pareto前沿
2. **拥挤度计算**：保持解的多样性
3. **遗传操作**：模拟二进制交叉（SBX）+ 多项式变异

### 4.3 参数边界

| 内阻 | 0.03 | 0.2 | Ω |
| V₀ | 3.9 | 4.3 | V |
| K | 0.01 | 0.3 | V |

## 5. 剩余时间预测

### 5.1 解析近似

假设电压近似恒定，可得解析解：

```
t_remaining = (SOC_current - SOC_target) · V_avg · Q_eff / P_total
```

### 5.2 数值求解

使用`scipy.integrate.solve_ivp`求解ODE，设置终止事件：

```python
def soc_zero(t, y):
    return y[0] - 0.05  # SOC降到5%
soc_zero.terminal = True
```

### 5.3 不确定性量化

采用蒙特卡洛方法：

1. 对参数添加高斯扰动（容量±200mAh，内阻±0.01Ω）
2. 运行N次模拟（N=100）
3. 计算统计量：均值、标准差、置信区间

## 7. 模型局限性

1. **简化假设**：假设各组件功耗独立，忽略了相互作用
2. **参数不确定性**：部分参数基于文献值，可能因设备而异
3. **老化模型简化**：采用线性老化模型，实际老化可能更复杂
4. **温度动态**：模型未考虑设备自身发热导致的温度变化

---

## 8. 结论

本报告建立了一个完整的智能手机电池连续时间数学模型：

1. **连续时间模型**：基于微分方程组描述SOC动态
2. **多因素考虑**：综合屏幕、CPU、网络、GPS、温度等因素
3. **卡尔曼滤波**：实现实时SOC估计和不确定性量化
4. **多目标优化**：支持参数估计和模型校准

模型可有效预测不同使用场景下的剩余放电时间，为电池管理系统和用户体验优化提供理论基础。
